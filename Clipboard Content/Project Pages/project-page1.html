Capstone Senior Project: Echo's Cry -Repository

This project has been nothing short of one of my greatest learning experiences and accomplishments. Early in development, I reached out to Chris Forkner, a Senior developer at Unity, and interviewed for the opportunity to gain Chris’ mentorship along the projects journey. Chris accepted, and my team and I began by initiating weekly sprint meetings, where we discussed technical issues, game-design ideas, and tracked our current progress. This weekly collaborative effort, along with a shared Github repository, has simulated a professional work environment for industry level computer science engineers.

Wrapping up the project in one tag line would describe the game as a, “Fighting game, set to the rhythm, in an intense wave-based, hack-and-slash adventure, battle to an upbeat soundtrack, and discover the Victorian fantasy world of Echo’s Cry”. However, if you were to ask how this project impacted me as a developer, I would remark on the learning experiences, struggles, and accomplishments I made as a part of an engineering team. The first hurdle came when integrating our project within the Github branch-based workflow. After understanding branch management and pull-requests, our team began to work seamlessly together to produce results rapidly and effectively. This allowed me to begin working on features for the game such as VFX systems, enemy and player behaviors, and rhythmic synchronization features that brought the project to life. To add to the personal challenge, I decided the models and sprites for the game would be hand-modeled, crafted, and animated. This required me to learn new systems like Blender where I practiced 3D modeling, texturing, and UV mapping with every new game asset created. I also began drawing and animating all 2D assets in Adobe Fresco, practicing vector-based art. Using an interdisciplinary approach of learning, I’ve been able to utilize a multitude of new systems quickly and adapt to our ever-changing system requirements. This project has represented a newfound passion for creativity, collaboration, and desire to learn in unfamiliar environments that I will take forward into my career.

The development of this project took place in the Unity engine and is written in C#. The project uses Unity’s frameworks for handling input, UI management, animation keyframing, component-based design, audio engineering, and VFX/shader creation tools. Blender was utilized to create all 3D assets, and the subsequent textures were sourced from “freepbr.com”. Special thanks to Christ Forkner from Unity, for technical support in engine debugging and optimization, as well as facilitating project progress and proper design techniques.
