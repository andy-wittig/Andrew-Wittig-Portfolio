Solar System Rendering Engine -Repository

Traverse through the solar system and explore the detailed planetary surfaces in this real-time rendering space flight simulator. The interactive model of the solar system supports both camera panning in the planetary orbital mode, and a first-person flight mode. Built in the OpenGL rendering pipeline in C++, the simulator renders complex 3D scenes with accurate reflectance lighting, physically based (PBR) materials, and a range of post-processing effects.

Designing this computer graphics system has reinforced best practices for planning larger-scale systems, carefully considering how each component should interact with one another. Developing this engine garnered valuable technical experience through writing GLSL shaders, animating ship pitch and roll as well as the planetary orbits using matrix mathematics, designing graphic engine architecture, and integrating external libraries such as Assimp for model loading and STB Image for texture processing. Visual fidelity was further enhanced by featuring bloom, HDR buffers, and normal and emissive lighting maps. To ensure the system maintained high performance and reliability standards, object instancing was implemented to efficiently render hundreds of asteroids in the surrounding belts.
